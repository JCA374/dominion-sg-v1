The model

Every model here is RL-v3's network: 413 inputs → 256 ReLU → 256 ReLU → 34 logits (one per card, or PASS) and a win estimate. One net answers every kind of decision (play an action, buy, trash, gain, discard…); the decision kind and the card it is about are part of the input. Nothing about the shape changes in this project: only the weights do.

How it learns here

Supervised step. For a verified improvement (teacher's winner b, c2's choice c, verified gain g) the loss is g · softplus(−(logit_b − logit_c)): it pushes the winner's logit above c2's, more for bigger gains. On a batch of c2's own positions (all decision kinds) it adds KL(c2 ‖ net) and the squared difference of the win estimates, so the net changes where the labels say and nowhere else. The rollout grades never become value targets.

PPO. The same clipped PPO as c2's own training: 3,000 games per iteration in the open league (its own past snapshots, earlier models, the GA base, bots, AZ; plus frozen c2 and c1 at 10% each), reward +1 / 0 / −1 at the end of the game, GAE λ 0.95, learning rate 2e-4, fresh Adam. The update now divides the logits by the sampling temperature, as the sampler does.
