Can search teach a Dominion network to play better than more self-play would?

RL-v3 c2 is the strongest network of this Dominion project. A slow rollout teacher (BV-v1) that tries every buy or action to the end of the game beats it by 9–12 points. Here c2 learns the teacher's verified improvements and then continues PPO (branch B), against the same PPO from plain c2 (branch A). A branch is promoted when it scores at least 53% against frozen c2 on 2,000 fresh kingdoms, both seats, with the paired 95% lower bound above 50%.

What this is

Dominion is a two-player deck-building card game: each turn you play action cards and then buy cards with the coins in your hand; whoever owns the most victory points when the game ends wins. Every model here plays the base set (26 kingdom cards; 10 per game) with the Steam rules.

c2 is a single network (413 inputs → 256 → 256 → 34 options + a win estimate) that answers every decision in one forward pass. The BV-v1 teacher answers a decision differently: for each candidate buy (or action), it copies the game, deals the hidden cards at random 32 times, plays each copy to the end with c2 for both players, and keeps the candidate that wins most often, but only when it beats c2's own choice by more than 2 points and 2 standard errors. Example: with $6 c2 buys Gold; the teacher finds that Laboratory wins 61% of the rollouts against Gold's 52%, and plays Laboratory. That teacher scored 59% against plain c2 (300 games), and 62% when it also chose actions, but it costs seconds per decision.

The question is whether that knowledge can be put into c2's weights, so it costs nothing at play time, and whether it survives further PPO training. A fair answer needs a control: the same PPO, the same games, from plain c2.

Approach

Four steps, in the order the handoff gives. 1. A matched ablation of the teacher (buy search, action search, both, and a plain mirror) on one frozen game manifest and one frozen build. 2. A pilot dataset: c2 plays, the teacher labels each decision, and the winner of each label is re-checked on 32 independent draws; a held-out bank of 1,000 positions is graded again with 128–512 draws for every legal option. 3. c2 is trained to put each verified winner above its own choice (a pairwise loss weighted by the verified gain), held to its own policy and value on 85,000 of its own positions. 4. Matched PPO: A from c2, B from the supervised c2, two training seeds each, the same 3,000 games per iteration on the same kingdoms.

 frozen manifests ──► 1 ablation (4 arms, 600 games each) ──► which teacher to label with
                                         │
 c2 plays, teacher grades ──► 2 pilot labels (20k) ──► verification draws ──► held-out bank
                                         │
 c2's own positions (anchors) ──► 3 supervised c2 ──► bank + dev match
                                         │
                        ┌────────────────┴────────────────┐
                 A: PPO from c2                    B: PPO from supervised c2
                        └────────────── 4 matrix + 2,000-kingdom promotion ──► decision

Numbers: the net has 181,000 parameters and plays a game in about 5 ms; a teacher game takes 6–11 s on one core (30–50 s when 7 workers share the 4-core laptop); one PPO iteration (3,000 games + update + 1,500 evaluation games) takes about a minute.
