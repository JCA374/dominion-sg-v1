Lessons

What this project and earlier ones taught. Newest first.

From this project

  • Check a PPO implementation's first ratio on real sampled data at every temperature you sample with; at temperature 1 a temperature bug is invisible.
  • Make the training stream depend on a seed, never on a run's name, and collect worker results in order: only then are two branches comparable game for game.
  • A labels-only mode must provably not change the game: test it by comparing scores and turns with the plain policy.
  • Measure an optimisation end to end before believing it: preparing each draw once cut the work 6.6× and saved no time.
  • Write a match's manifest before its first game, and check resumed rows against it.
